Connect your command table

The extension edits the running PC game. It does not launch a second game or upload your saves.

First-time setup

  1. Extract the complete Belde download. In Chrome or Chromium, open chrome://extensions, enable Developer mode and choose Load unpacked. Select the download's extension folder.
  2. Run the native-host installer for your platform from the native folder. Follow native/README.md; Windows registers a native executable for your user, while macOS needs Python 3 or a locally compiled host.
  3. Start the Belde desktop game. Find its six-digit editor pairing code in the game.
  4. Open this extension, enter that code, and choose Pair. Use Open full editor for larger maps.

While playing

Drag units, towers and traps onto the map. Guard holds position, Patrol follows its track while attacking, and Advance moves toward enemies. Range previews and hatched collision warnings help you place objects; the PC performs the final validation. During combat, layout edits wait for a safe planning phase.

Undo and redo operate on authored layout history. If a conflict appears, refresh the PC layout and review it before trying the edit again. The editor never silently overwrites a newer game layout.

Sessions and reconnecting

One PC gameplay process and one authorized editor session form one connected pair. Popup and full-editor windows share that editor connection. Heartbeats keep it alive; an abandoned editor lease expires after 15 seconds, so a browser crash does not permanently lock you out.

If another editor is connected, enter the current code from the PC game and explicitly choose Disconnect other session to continue. You can also disconnect the editor from the PC.

Connection troubleshooting

  • Native host not found: run the correct installer after extracting the files; keep the native executable at its installed path.
  • Start Belde: the desktop game must be running on the same computer as Chrome.
  • Pairing expired: re-enter the code currently displayed in the game.
  • Only one game instance: close the other Belde process, then reopen the game.
  • Custom port: the game and host must inherit the same BELDE_BRIDGE_PORT. The supported default is 43127.

Scope and privacy

The default bridge listens only on this computer's loopback address. No remote account service is deployed by default, so the local lease cannot enforce account limits across two unconnected computers. An optional self-hosted profile coordinator is included; see native/session-README.md for authenticated cross-device setup. No tokens or pairing codes are written to browser storage. Saves remain local to the PC game.
